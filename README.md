## ⚡ EXECUTIVE OVERVIEW

This repository houses the mission-critical, enterprise-grade election monitoring and rapid mandate defense platform custom-engineered for **Abubakar Malami, SAN, CON**, former Attorney-General of the Federation & Minister of Justice, for the **2027 Kebbi State Gubernatorial Election**.

Engineered by **GetoCore Digital Innovation** in technical partnership with **TEEM TECH Solution**, this platform provides end-to-end command and forensic oversight across all **3,745 Polling Units**, **225 Registration Areas (Wards)**, and **21 Local Government Areas** of Kebbi State.

## 🚀 LOCAL DEVELOPMENT & PRODUCTION RUN

```bash
# Clone the repository
git clone https://github.com/KararaDMaiyaki83/malami-adc-monitor.git
cd malami-adc-monitor

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
